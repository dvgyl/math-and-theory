# Fresh replay record

This directory records the fresh verification of this package, run for its publication on 3 November 2026.

- [`build.log.xz`](build.log.xz): `lake build OneSidedF3` in a fresh copy of [lean/](../lean/) with no project build output, using Lean 4.19.0 (commit `6caaee842e94`) on Linux x86_64 and the pinned Mathlib `c44e0c8ee63ca166450922a373c7409c5d26b00b` from its official build cache. The local replay used the unchanged lakefile and manifest, with the dependency directories linked to a local checkout of the pinned Mathlib revision. All 43 project modules and the audit module compiled from source in about eleven minutes on one core.
- [`axiom-inventory.json`](axiom-inventory.json): the output of `scripts/check_axiom_audit.py` on that log. The audit covers 850 declarations defined in the 41 modules that define declarations, including all 490 declarations named in the sources. The 604 declarations other than Lean 4.19 code-generation auxiliaries include 503 theorems, and all 604 depend only on `propext`, `Classical.choice` and `Quot.sound`. The 246 auxiliaries depend in addition only on other auxiliaries and, for 11 of them, on the code generator's placeholder `lcProof`. The main theorem `FilteredF3.equation10_both_closed_forms` depends on exactly the three standard axioms.
- [`checks.log`](checks.log): `python3 checks/run_checks.py --independent` with Python 3.13, NumPy 2.3.5, SciPy 1.17.0 and SymPy 1.14.0. All seven package checkers and the brute-force comparison passed. A first version of the brute-force comparison used too tight a tolerance when selecting real eigenvalues. In one case it therefore missed a defective top eigenvalue (the hard case) and reported a spurious discrepancy of 0.04. The tolerance was corrected; the search and the exact evaluators agree.

The upload's own verifier compiled a single amalgamated source file. That route and its receipt are not included; this record replaces it with a modular build. Compiled objects are not included. The CI workflow repeats the Lean build, the audit and the standard-library Galois certificate on every push.
