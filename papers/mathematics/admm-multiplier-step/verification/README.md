# Fresh replay record

This directory records the fresh Lean replay of version 1.1 of this package, run on 31 October 2026 (all 301 modules, status passed, not resumed).
The run used Lean 4.19.0 (commit 6caaee842e94) on Linux x86_64 and a clean checkout of Mathlib
c44e0c8ee63ca166450922a373c7409c5d26b00b with the compiled Mathlib modules of its published build cache (`lake exe cache get`).
Every local module was compiled from source into a fresh output directory by the package's own verifier, one module at a time;
the module compilations took 5460 seconds in total and the central audit 45 seconds.

Machine-specific paths in the logs are replaced by `$REPLAY` (the replay working directory), `$LEAN_HOME`
(the Lean distribution), `$MATHLIB` (the Mathlib checkout), `$PACKAGES` (the directory of the pinned dependency checkouts),
`$DEPS` (the dependency project passed to the verifier) and `$ELAN_HOME`. Lean files generated by the verifier,
such as the axiom-audit file, are stored with a `.txt` suffix so that they are not mistaken for package sources.
Compiled objects are not included.
The CI workflow repeats the replay on every push.
