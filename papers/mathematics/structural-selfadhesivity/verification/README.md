# Fresh replay record

This directory records the fresh Lean replay of this package run for its publication on 30 October 2026.
The run used Lean 4.35.0-rc3 (commit 470d5ce14007) on Linux x86_64 with the dependency checkouts pinned in
`proof/e3_lean/lake-manifest.json`; the Mathlib objects at revision 0db6cb99b412983de54b59ecc1b0b2747542cda3
came from the official Mathlib cache. The package's own verifier copied the sources into a fresh directory with no
compiled project objects and compiled every package module from source, one at a time, before auditing the endpoints.

Machine-specific paths in the logs are replaced by `$OUTPUT` (the verifier's output directory), `$PACKAGE`
(the unpacked package), `$PACKAGES` (the dependency checkouts), `$REPLAY`, `$LEAN_HOME` and `$ELAN_HOME`.
Lean files generated by the verifier are stored with a `.txt` suffix so that they are not mistaken for package
sources. Compiled objects and the fresh source copy are not included. The exact certificate checks are in
`positive-check.json` and `negative-check.json`, and the comparison of the Lean CI table with the manuscript table in `scope-pattern-check.json`. The CI workflow repeats the replay on every push.
