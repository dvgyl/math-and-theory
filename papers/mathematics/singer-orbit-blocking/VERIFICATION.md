# Verification

The Lean project in [lean/](lean/) pins Lean `v4.35.0` and Mathlib `56a005855ea17e0b0958f73ec801ae140b0a1679`, the revision of the shared library; [lake-manifest.json](lean/lake-manifest.json) fixes every transitive dependency. Install [Elan](https://github.com/leanprover/elan), then, in a fresh copy of the package, run

```sh
python3 verify.py --output /tmp/singer-orbit-blocking-verification
```

The script rejects `sorry`, `admit`, `axiom`, `native_decide` and other unchecked constructions in the Lean sources, refuses to reuse an existing project build, fetches the pinned Mathlib cache for the imported modules, builds the library and runs [Audit.lean](lean/Audit.lean). The audit collects the transitive axioms of every declaration defined in the project modules, including the 342 certificate searches, and fails unless each depends only on `propext`, `Classical.choice` and `Quot.sound`; the script also requires this for every declaration listed in [theorem-map.json](theorem-map.json). It then runs the exact checker, which uses only the Python standard library. `python3 verify.py --skip-lean` runs the exact check alone. The kernel search takes about an hour of processor time in total; Lake builds the certificate modules in parallel, and each needs up to about 3 GB of memory.

`SingerC3.Point` and `SingerC3.Line` are both `Projectivization (ZMod 13) (Fin 3 → ZMod 13)`, and `SingerC3.lineSet ℓ` is the set of points orthogonal to `ℓ` under the dot product. `SingerC3.singer` is the projectivity of the matrix of multiplication by `θ` on `F₁₃[θ]/(θ³ + θ + 6)` in the basis `1, θ, θ²`, and `SingerC3.hgen = singer^[61]`. `HInvariant B` says that `hgen` maps `B` into itself, `IsBlocking B` that `B` meets every line, and `CapAtMost B c` that every line meets `B` in at most `c` points. The main theorem `SingerC3.isLeast_admissibleCaps` states `IsLeast admissibleCaps 5`, where `admissibleCaps` is the set of `c` for which an `H`-invariant blocking set with `CapAtMost B c` exists.

The finite facts about the coordinate model are decided by the kernel with `decide +kernel`. The reduction (`SingerC3.reduction`) applies to every `H`-invariant point set and translates a chosen orbit to orbit 0. The 61-variable system is refuted by `SingerC3.go`, a depth-first search evaluated by the kernel. Each search step is checked against the line counts: a node is closed by a line meeting at least five chosen points or only excluded points, an orbit is excluded or chosen only after checking that the opposite choice closes the node, the free orbits of a line already meeting four chosen points are excluded, and otherwise the search splits on an orbit. A heuristic on packed line counts chooses the steps; `SingerC3.go_sound` holds for every value of the heuristic, so it is not trusted. The top search (`SingerC3.Cert.top`) stops at 342 partial assignments, each closed by a theorem `search o z = true` in `SingerC3.Cert.Part00`–`Part15`.

The exact checker [check_singer.py](certificate/check_singer.py) was written for this release. It rebuilds the field and all points and lines from their coordinate equations, checks that the lines are the translates of the difference set `D`, checks the 61 conditions and the identity `MMᵀ = 13I + 3J`, checks the witness, its intersection numbers, its tangents and its conjugacy to the set of Blokhuis, Brouwer and Wilbrink, and repeats the exhaustive search with its own propagation rules.

The fresh replay for this release is recorded in [verification/](verification/). Formal verification does not establish novelty or priority.
