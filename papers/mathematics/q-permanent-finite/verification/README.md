# Fresh replay record

This directory records the fresh verification of this package run for its publication on 1 November 2026.

- [`build.log`](build.log): `lake build QPermanentResearch QPermanentResearch.AxiomAudit` in a fresh copy of `lean/` with no project build output, using Lean 4.19.0 (commit `6caaee842e94`) on Linux x86_64 and a checkout of Mathlib `c44e0c8ee63ca166450922a373c7409c5d26b00b` whose modules came from the Mathlib build cache (`lake exe cache get`). All 32 project modules, the aggregate module and the audit module were compiled. The warnings are style linter messages.
- [`axiom-inventory.json`](axiom-inventory.json): the output of `scripts/check_axiom_audit.py` on that log. The audit covers all 2068 declarations defined in the project modules. The 749 declarations other than code-generation auxiliaries are theorems, definitions and inductive constructions, none an axiom, and depend only on `propext`, `Classical.choice` and `Quot.sound`. The other 1319 are auxiliary declarations that the Lean 4.19 code generator stores for executable definitions (names ending in `_cstage1`, `_cstage2`, `_spec_k`, `_elambda_k`, `_closed_k` or `_boxed`); beyond the standard axioms, 310 of them refer to the code generator's placeholder `lcProof` (120 of them) or to other auxiliaries, which the audit permits for auxiliaries only. No other declaration depends on them through an axiom.
- [`certificate-check.json`](certificate-check.json): the output of `python3 certificate/verify_certificate.py --recompute --primes 4`, which also rebuilt the GMP orbit-recurrence program, recomputed both witnesses and recomputed the residues for four recorded primes.

The residue record [`certificate/crt_residues.json`](../certificate/crt_residues.json) was produced for this release by running `row_residues.cpp` on all 500 primes, in two processes of 250 primes each. The Chinese-remainder reconstruction in `verify_certificate.py` recovers from it `per(B)`, the three-component norm `U` and the full wedge norm `T`, each equal to the frozen integer in [`certificate/witness896_cap32_exact.json`](../certificate/witness896_cap32_exact.json); the only nonzero parity classes are the five predicted by the four-row decomposition.

Machine-specific paths do not occur in these records. Compiled objects are not included. The CI workflow repeats the Lean build, the audit and the short certificate recomputation on every push.
