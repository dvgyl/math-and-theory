# Fresh replay record

This directory records the fresh Lean replay of this package run for its publication on 30 October 2026 (all 32 modules, status passed).
The run used Lean 4.19.0 (commit 6caaee842e94) on Linux x86_64 and a clean checkout of Mathlib
c44e0c8ee63ca166450922a373c7409c5d26b00b whose required modules were built from source on the same machine.
Every local module was compiled from source into a fresh output directory by the package's own verifier.

Machine-specific paths in the logs are replaced by `$REPLAY` (the replay working directory), `$LEAN_HOME`
(the Lean distribution), `$MATHLIB` (the Mathlib checkout) and `$ELAN_HOME`. Lean files generated by the verifier,
such as the axiom-audit file, are stored with a `.txt` suffix so that they are not mistaken for package sources.
Compiled objects are not included.
The CI workflow repeats the replay on every push.
