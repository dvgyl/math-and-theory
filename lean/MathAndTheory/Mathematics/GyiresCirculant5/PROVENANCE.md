# Source and changes

These files come from Dev D. Goyal's order-five Gyires project. The source commit is `72cf49a51be42cf15592f91d991f0b0c76f58448` at https://github.com/dvgyl/gyires-circulant-5.

The original project records that GPT-6 with Pro reasoning found the proof and wrote the original Lean development. It records that Claude Opus 5.5 ported the project to Lean 4.35 and added the Mathlib statements, formalized remarks, and Challenge/Solution correspondence. These are historical source disclosures. The current audit did not verify the historical model identities.

The collection changes module paths and namespaces. It preserves the mathematical proof scripts apart from those names. It adds source notices and preserves the existing notice in PermanentGram.lean. The source-map.json file in verification/gyires-circulant-five records both sets of hashes. The original repository was not changed.
