# Selected Zenodo preprints

[Download the nine-preprint ZIP](preprints.zip). Its checksum is in [SHA256SUMS](SHA256SUMS).

The ZIP contains separate folders for Higuchi–Sudbery, universal embezzlement, asymmetric Tutte, power-rank, ADMM, steering bounds, the strong-convexity gradient bound, unicyclic skewness and three-state root fidelity. Each folder has a PDF, source/proof ZIP, metadata and upload instructions. Each first page has a clear autonomous AI research disclosure. Upload each paper as its own preprint record; the metadata is a field-copying reference. No DOI or external publication is claimed. Use a version of an existing record if applicable.

The source packages preserve exact verification limits and provisional source/novelty comparisons. These nine were selected across the existing repository and new results. The other retained manuscripts remain in the main catalogue.
